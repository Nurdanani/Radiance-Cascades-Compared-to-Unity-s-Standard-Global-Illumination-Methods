# Radiance Cascades Compared to Unity's Standard Global Illumination Methods

Experiment setup for the DIGRA conference paper
**"Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP"**.

## Overview
This repository contains the measured data and materials used to compare
Radiance Cascades with Unity's standard real-time global illumination
methods in the Universal Render Pipeline (URP).

## Repository Structure
